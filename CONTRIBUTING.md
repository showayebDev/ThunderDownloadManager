# Contributing to Thunder Download Manager (ThunderDM)

Thank you for your interest in **Thunder Download Manager**! We appreciate the community's support, feedback, and ideas in making ThunderDM the best desktop download manager.

---

## 🚫 Policy on External Pull Requests

> [!IMPORTANT]
> **We do NOT accept external code Pull Requests (PRs) at this time.**
> 
> Thunder Download Manager is currently developed and maintained exclusively by the core author. Any pull requests opened by external contributors will be politely closed without review.

---

## 💡 How You CAN Contribute

While direct code contributions via PRs are not accepted, there are many meaningful ways you can help improve ThunderDM:

### 1. 🚀 Submit Feature Requests
Have an idea for a new feature, UI enhancement, or downloader capability?
- Head over to the **[Issues](https://github.com/showayebDev/ThunderDownloadManager/issues)** tab.
- Click **New Issue** and describe your suggested feature, why it would be useful, and how you envision it working.

### 2. 🐛 Report Bugs & Glitches
Found a broken download, stream error, UI glitch, or crash?
- Open a bug report under **[Issues](https://github.com/showayebDev/ThunderDownloadManager/issues)**.
- Please include:
  - Your Operating System and version (e.g. Windows 11, macOS Sequoia, Ubuntu 24.04).
  - ThunderDM app version.
  - Clear steps to reproduce the issue.
  - Screenshots or error logs if available.

### 3. 🌐 Test & Provide Feedback
- Test new release binaries across different platforms and network environments.
- Help verify browser extension compatibility with new browser updates.
- Share performance benchmarks or suggestions in Issues.

### 4. ⭐ Star and Share the Project
- Star the repository on GitHub to show your support.
- Share ThunderDM with fellow developers and users looking for a fast, modern download manager.

---

Thank you for understanding and helping build a better Thunder Download Manager!
